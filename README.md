# Notepad View

基于 Python、PySide6 和 Scintilla 的 Windows 文档编辑器，支持 Markdown、TXT/日志、JSON/JSONL、YAML、XML、HTML、CSS/SCSS、JavaScript/TypeScript、SQL、Python、INI/TOML、CSV/TSV（新增类型仅在源码版生效，尚未重新打包）。

## 安装与启动

运行 `dist/NotepadView-1.0.0-Setup.exe`，选择安装目录并点击安装。安装包包含 Python 和 Qt，无需另装 Python。默认安装到当前用户的 LocalAppData/Programs/NotepadView，可创建桌面及开始菜单快捷方式。

安装后，MD、Markdown、TXT、JSON、XML、SQL 文件的“打开方式”中可选择 Notepad View。安装不会修改已有默认打开程序；卸载会清理指向本安装的候选注册。

也可以解压 `dist/NotepadView-1.0.0-Windows-x64-portable.zip`，运行其中的 `NotepadView.exe`。安装后应用、开始菜单和桌面快捷方式均显示为 Notepad View。移动便携版时需保留整个目录。

Windows 安装器内部载荷使用固实 TAR.XZ 无损压缩，跨文件共享压缩字典以进一步减小体积；安装程序内置兼容读取，完整保留 Qt、LibreOffice、Calibre 和许可文件，不减少阅读、转换或编辑功能。便携 ZIP 仍使用最高级别 Deflate，以兼容 Windows 资源管理器解压；安装后的磁盘占用不变。压缩构建会耗时更长。仅重新压缩已有发行目录可运行 `.venv\Scripts\python.exe scripts\build.py --setup-only`；源码有修改时应运行 `build.ps1` 完整重建。

## Office 与电子书阅读器运行时

- `.doc`、`.xls`、`.ppt`、`.pptx`、`.odt`、`.ods`、`.odp`、`.rtf` 以只读 PDF 预览；`.epub` 以章节阅读器打开，`.mobi`、`.azw3`、`.fb2` 先转换为 EPUB 再阅读。新增格式均不写回源文件，电子书目录、章节、缩放和滚动位置会随工作区恢复。
- Office 转换使用随应用打包的 LibreOffice，MOBI/AZW3/FB2 转换使用随应用打包的 Calibre。EPUB 脚本和远程内容被禁用；不支持 DRM 电子书。损坏、加密或转换引擎无法读取的文件会显示错误，不会降级为乱码文本。
- Windows 打包会先自动准备 LibreOffice 26.2.6、Calibre 9.17.0：从上游下载固定版本 MSI，校验 SHA256，提取到 `build\reader-runtimes`，不安装到系统。首次构建需要联网，后续复用缓存；可运行 `.venv\Scripts\python.exe scripts\build.py --prepare-runtimes` 单独准备。完整引擎和随附许可文件会收入安装包及便携版，用户安装后无需另装阅读引擎。下载或提取失败会在主程序打包前终止，保留提取日志，重新打包可重试。仍可用 `NOTEPADVIEW_LIBREOFFICE_DIR` 与 `NOTEPADVIEW_CALIBRE_DIR` 指定自备完整运行目录；Windows 目录须分别包含 `program\soffice.exe` 和 `ebook-convert.exe`。macOS 仍需提供对应原生目录，分别包含 `LibreOffice.app\Contents\MacOS\soffice` 和 `calibre.app\Contents\MacOS\ebook-convert`。
- LibreOffice 与 Calibre 的发行包及版本会影响许可证、NOTICE 和源代码义务。发布者必须先核查对应版本的许可要求，并在打包运行时目录中保留并随包提供所需声明；当前仓库不包含这两个引擎，也不宣称已完成其再分发许可审查。详见 `THIRD_PARTY_NOTICES.md`。

## 功能

- **API 工作台**：主菜单可切换到独立 API 请求区；支持 Swagger 2.0、OpenAPI 3.0/3.1 JSON/YAML（本地文件、URL 或粘贴导入）。左侧树的第一个顶层节点固定为“接口管理”，不可删除或重命名；该节点同行右侧依次提供新增、批量选择和删除图标按钮，批量按钮选中后可再次点击退出。点击根节点返回根目录。选中“接口管理”或模块时右侧请求和响应区域全部禁用，选中具体接口后恢复可用。模块和直属接口均为根的子节点，模块接口为第三级节点，历史记录单独显示为顶层节点；选中模块或模块内接口时，新接口归入该模块。新增菜单直接创建未命名模块/接口并行内编辑，双击可重命名，不弹输入或归档选择框。已有归档保留为模块，仅清理空的旧默认归档；根接口使用独立内部集合持久化，不重复迁移。删除需确认，批量选择可再次点击按钮或 Esc 退出并清除勾选。配置区提供 Params / Body / Headers / Auth / Cookies / 变量 / 脚本页签：参数使用可增删表格，Query 保留重复名称和启用状态；Body 提供 raw 文本、form 表格、multipart 文本/文件表格及 binary 文件选择，认证提供 none / bearer / basic / api_key 表单。顶部固定方法、URL、发送和保存按钮。新请求可直接调试，发送及完成回调均不自动创建或覆盖已保存请求；新增节点和行内名称立即持久化，请求内容修改仅点击保存才持久化。修改显示“保存 *”，切换请求或新增接口时不再弹出未保存确认，未保存的请求内容直接放弃；切换环境保留编辑内容。历史支持响应回顾和回放，认证、Cookie 和敏感请求头遮罩显示，未修改的遮罩字段回放时恢复原值。默认提供开发环境、测试环境和生产环境；新建及编辑环境时在同一表单展示名称、Base URL、默认请求头和加密变量。Base URL 可暂时留空，使用相对请求路径前需填写有效地址；集合和请求变量可覆盖环境值。请求支持 Query、Headers、Basic/Bearer/API Key 认证、Cookie、Raw、表单、multipart 与二进制正文；请求前/响应后 JavaScript 在受限子进程中执行并有硬超时。HTTP/HTTPS 请求由本机直接发送，TLS 校验保持开启；状态、耗时、响应正文和断言结果在工作区显示，最近 100 条完整历史保存到与文档缓存分离的 SQLite。敏感数据以 AES-GCM 加密并使用系统密钥库保护；不提供 Postman Collection 导入/导出。**OAuth 2.0 授权码 + PKCE 和 Client Credentials 流程尚未实现。**

- Word `.docx` 和 Excel `.xlsx` 使用现有查看器，行为保持不变；旧版及其他 Office 格式按上文转为只读 PDF 预览。所有受支持的 Office 格式仅支持打开查看，不提供新建；`.docx`/`.xlsx` 也不提供保存、另存为或撤销/重做。Word 可查看正文、表格、基本文字格式及内嵌图片；Excel 可查看单元格、公式文本及切换工作表，公式不执行、不重新计算。复杂排版和高级对象可能无法完整显示。

- Markdown 源码编辑、实时预览、仅源码/双栏/仅预览。界面保留编码转换功能完成时的经典 IDE 布局、四主题配色与行号底色；导航、文件、源码和预览共用整体工作区，仅最外侧四角采用 2px 真实圆角裁剪，上下各留 1px 外间距，左右及内部间隔保持原样，内部面板直线连接。
- 文件右键提供“另存为…”，保存右键选中的文本、图表或可编辑图片，保留当前编辑文件；只读图片和 PDF 不提供此操作。
- 纯文本 `.txt` 编辑与原文预览，可从“文件 → 新建纯文本”开始。
- 编辑区和预览区右下角分别悬浮一键到顶、到底按钮，点击任一栏按钮可同步定位两栏。
- 标题、列表、待办、表格、引用、代码高亮、图片和链接。
- 首次启动为空白工作区，不载入示例文档；以后启动恢复上次工作区与当前文件。
- 新建、打开、保存、另存为、最近文件、未保存更改提醒。新建类型列表新增“未指定类型”：草稿显示“未命名”，按纯文本编辑，首次保存时选择文件类型；未输入后缀时按所选类型补齐，保存后按文件类型显示。取消保存保留草稿，工作区可恢复未指定类型状态。
- 点击底部当前编码，可选择 ANSI、UTF-8、UTF-8BOM、UTF-16 BE BOM、UTF-16 LE BOM。菜单上组按指定编码重新读取磁盘以修正乱码；有未保存内容或编码修改时先确认，读取失败完整保留原文档。草稿无磁盘文件时禁用重读，图片/PDF/图表禁用编码菜单。下组“转为…”保留文字、选区、正文撤销、手动类型和视图，仅改变保存编码并标记修改，Ctrl+S 才写入磁盘；编码与修改状态随工作区恢复。ANSI 使用 Windows 当前系统代码页，其他系统使用本地首选编码；即使系统代码页为 UTF-8，显式选择 ANSI 仍显示 ANSI。编码读写严格拒绝无法表示的字符，不以替换字符丢失内容；UTF-8 与 UTF-8BOM 分开保存，UTF-16 两种字节序均写入对应 BOM，重读时相反字节序的 BOM 会报错。
- 打开对话框与资源管理器拖放共用入口，支持任意后缀及无后缀文本；多个文件分别加入文件树。每次重复打开同一路径均确认是否用磁盘内容覆盖，拒绝后保留原内容。磁盘目录与远程拖放链接跳过。
- SVG 可点击选择普通图形或文字，修改填充色、描边色及文字字体、字号，保存仍保留 SVG 元素；按元素包围框、从最上层开始选择，支持祖先变换，不提供复杂路径绘制或精确轮廓命中。为安全起见，拒绝 DTD、实体、处理指令、脚本、嵌入网页和外部资源引用的 SVG。
- PNG/JPG/JPEG 可添加文字，点击选择并拖动，修改文字颜色、字体及字号。SVG/PNG/JPG/JPEG 在缩放按钮前提供“水平翻转”“垂直翻转”，整体镜像图像与文字字形，连续同向翻转两次还原；翻转不改变查看缩放，调整尺寸后仍可翻转。位图保留无损原图及可编辑文字层，翻转后新增文字按正常方向显示，可继续拖动和修改样式；翻转及文字方向随撤销/重做、工作区快照恢复。SVG 保留 defs、viewBox 和矢量元素，翻转后仍可点击选中修改样式，保存重开保留镜像效果。保存将文字合成为图片，PNG 保留透明背景，JPEG 透明区域铺白；工作区仍保留可编辑文字层，外部重新打开导出的位图时文字已合并。
- 上述图片可输入实际像素宽高，勾选“等比例”联动后点击“应用尺寸”；支持独立撤销/重做、Ctrl+S 保存及另存为（SVG 保留 `.svg`，位图可选 `.png`/`.jpg`/`.jpeg`）。切换文件保留编辑历史，工作区恢复图片内容、文字层、撤销历史及修改状态；关闭修改中的页签仍询问保存。尺寸每边最多 32768 像素且总计最多一亿像素；大量图片或长编辑历史会增加缓存体积。
- 图片、PDF 和脑图/流程图首次打开、恢复或切换进入时默认适应窗口，进入后仍可手动缩放。图片支持放大、缩小与适应窗口。其他图片格式继续使用 Qt 静态只读预览。图片/PDF 禁用 HTML 导出、格式工具和查找替换；只读图片和 PDF 禁用保存和另存为，切回文本后恢复。
- PDF 使用 Qt 原生只读预览，仅支持打开、上一页/下一页、页码跳转、缩放和适应窗口；不提供文字编辑、拖动、样式、撤销/重做、保存或另存为。工作区仅恢复磁盘文件与查看位置，旧 PDF 编辑缓存不再恢复或写入原文件。
- 音视频、压缩包、可执行文件及其他未知二进制或无法可靠解码的文件，仅提示不支持，不启动系统关联应用，不创建文本页签。损坏、加密 PDF 或无法解码的图片显示错误。图片按静态帧显示，支持格式取决于 Qt 图像插件。
- 新建可选择上述全部文本类型；新文档保持空白，加入当前分类。
- 编辑框顶部的“语言”下拉按钮和“编辑 → 文本类型”菜单可切换文本类型，并同步修改文件扩展名、语法高亮和预览。已保存文件直接更改磁盘文件名，未保存的编辑内容仍需手动保存；目标文件已存在时拒绝覆盖。草稿同步更新名称，阅读预览和图表禁用此功能。
- 新建窗口按文档类型与后缀排列，支持键盘选择和双击新建；弹窗按钮统一为中文。
- 文件栏采用“分类 → 文件”两级树，显示序号、文件图标、格式与修改标记；文件行没有关闭按钮，长文件名可悬停查看完整路径。
- 支持新建、双击行内改名和删除虚拟分类；始终保留一个名为“默认分类”的初始分类（可改名、不可删除），旧配置中的“未分类”自动更新为“默认分类”。右键文件可移除、批量选择、归类、打开所在文件夹，也可拖动文件到分类。右键不切换编辑内容；删除自定义分类后文件返回默认分类，移除文件只清除工作区记录，不删除磁盘文件。鼠标停在文件上点击滚轮中键，可快速移除该文件；有未保存修改时仍会询问确认。中键点击分类或空白区域无操作。分类右键菜单提供“新建文档”（直接归入该分类）和“批量选择”（选中该分类下全部文件），选中后右键文件可批量移除；空分类的批量选择不可用。
- 分类右键可新建文档并选择类型，文档直接归入该分类；文件右键、“文件 → 重命名”或 F2 可修改名称。草稿名称随缓存恢复，已保存文件在原目录改名，保留未保存内容且不覆盖同名文件。
- 全部打开文档（包括未保存草稿）自动缓存，退出时保存完整工作区，启动恢复分类、内容、当前文件、选区、滚动位置和每个文件独立的源码／预览／双栏模式。查找替换保持当前视图选择，预览模式下也不会自动展开源码。缓存失败会提示并保留窗口。
- 每个分类内的文件从 1 独立连续编号，页签与文件树使用同一编号；关闭、移除、批量移除、移动文件或删除分类后立即重新编号。
- 打开、另存为、切换文件和恢复工作区时，按当前路径的明确文本后缀识别自动类型（如 `.json` 使用 JSON，`.jsonl` 使用 JSONL）；`.txt`、`.log`、无后缀及未知后缀继续内容智能识别，通常检查开头最多 64 KiB；大数组仅在全文不超过 1 Mi 字符且严格 JSON 解析成功时识别，超过此上限的数字/字符串数组保守回退后缀；例如 JSON 放在 `.txt`、`.log`、无后缀或未知后缀中仍可高亮、格式化及进入修复。JSONL 保持逐行记录；结构引号转义的 JSON 也可识别。代码结构、弱特征或歧义输入保守回退后缀或纯文本，不能保证识别所有语法。图片/PDF/图表先走原有专用入口。
- 新建时明确选择的类型，以及“编辑 → 文本类型”手动切换的类型，在后缀未变时随页签、保存、重复打开、重命名及工作区恢复保留；草稿首次保存保留所选类型。实际路径后缀改变时清除旧类型覆盖，按新后缀或内容重新识别；Python 草稿默认使用 `.py` 后缀。打开时不格式化，保存保留原路径、编码和换行；另存为使用输入的准确文件名，不自动添加后缀。恢复类型使用缓存中的未保存内容，不重新读取磁盘覆盖缓存；旧路径缺失时不猜测同名新后缀文件，外部改名后打开新路径会建立独立页签。不在每次键入时扫描全文。
- 全部类型提供离线 Pygments 高亮（CSV/TSV 使用本地分隔文本词法器）；Markdown 保留渲染预览，TXT 保持原文，其他代码类型显示高亮代码。HTML 预览直接显示当前编辑内容的网页效果，支持内嵌 CSS、JavaScript 及可访问的在线样式、脚本、图片；已保存文件的相对引用以所在目录为基准，在线资源遵循浏览器的网络、证书及跨域规则。
- Python、PowerShell（`.ps1`）源码区提供“▶ 运行”：先保存当前内容（草稿先选择路径），再在独立 PowerShell 终端中执行，工作目录为文件所在目录，支持终端输入，结束后保留窗口。取消保存则不执行。Python 优先使用脚本所在项目及父目录的 `.venv/Scripts/python.exe`，其次使用源码版当前解释器；打包版查找系统 `py -3` 或 `python`，缺失时提示安装。PowerShell 使用系统 `pwsh` 或 `powershell`，遵循系统执行策略。目前脚本运行仅支持 Windows，其他语言不提供运行按钮。以上功能仅在源码版生效，尚未重新打包。继续使用现有依赖；构建配置已收集 Pygments 全部词法器，无新增依赖。
- “编辑 → 格式化文档”（Ctrl+Shift+F）：JSON/XML 两空格缩进，SQL 关键字大写及四空格缩进；JSONL 逐行压缩空白，保留多条记录、重复键、数值词法、空行和末尾换行，任何一行无效则整体拒绝，不转数组。优先格式化选区，无选区处理全文，可一步撤销，解析失败保留原文。XML 拒绝 DTD/实体声明，保留混合内容、xml:space 和声明编码；无模式定义时，元素之间空白按排版处理。SQL 使用现有 sqlparse，保留相邻字符串之间有意义的换行；并非所有数据库方言的语义验证器。

## 文件与预览说明

新建文档使用 UTF-8；打开文本严格识别 UTF-8（含 BOM）、带 BOM 的 UTF-16/UTF-32，以及可严格往返的 GB18030（兼容常见 GBK）。保存及另存为沿用已识别编码、BOM 和统一的换行风格（混合换行统一为 LF），无法用原编码表示的字符会阻止保存并保留磁盘原件。未知编码及含二进制控制字节的内容不会强行按文本编辑。所有文本保存使用同目录临时文件原子替换。`.txt` 按纯文本读写和预览，换行保留，Markdown 符号与 HTML 标签均按原文显示；Markdown 预览中的 HTML 标签也按文本显示，不运行脚本。Markdown 支持本地相对路径图片和 HTTP/HTTPS 图片；网络图片需要联网。点击外部链接会调用系统默认浏览器。

HTML 导出保留 Markdown 图片链接，并记录原始文档目录以解析本地图片。跨电脑分享时需一并携带图片并调整链接；当前版本不内嵌图片。不包含公式、Mermaid、DOCX/RTF 或富文本所见即所得编辑。

工作区缓存默认位于 `%LOCALAPPDATA%/Notepad View/workspace.sqlite3`，使用 Python 内置 SQLite，无需额外依赖。事务提交并校验后原子替换数据库，旁边的 `.bak` 保存上一份有效快照；主库损坏时尝试备份，遇到未来版本或无法恢复的缓存时停止保存，避免覆盖。首次使用会只读迁移同目录的旧 `workspace.json`（必要时读取其 `.bak`），保留旧文件；迁移失败不会清空或覆盖旧缓存。主题、侧边栏、默认视图等界面偏好仍使用 QSettings。`WorkspaceStore` 的 `load/save/close` 接口保持兼容，显式 `.json` 路径仍使用原 JSON 存储。缓存为本地明文，不上传；它独立于原文件，只有手动保存才写入原文件。自动缓存通常在停止操作约 0.8 秒后写盘，持续编辑每 5 秒尝试缓存；突然断电可能丢失最后一小段尚未缓存的输入。文本缓存记录原编码；可编辑图片缓存内容及独立撤销历史；PDF 和只读图片仅缓存路径和查看位置，PDF 还保存当前页，重新进入时默认适应窗口，源文件丢失时预览不可用。重复启动会激活已有窗口并转交文件路径，避免不同窗口覆盖同一工作区。

JSON 修复处理注释、尾逗号和完整的单引号字符串，保留数值字面量、重复键及顺序；支持保守移除字符串外属性名两端多余的 `\"`（属性名内部无转义且后接冒号），已有合法字符串中的嵌套 JSON、路径、Unicode 和换行转义仍按 JSON 字符串解释，不递归解码。对未包外层引号的整层转义对象/数组，可按 JSON 字符串规则逐层解码（最多八层，遇到合法 JSON 立即停止）；完整顶层对象后仅多出一个 `}` 时，可在差异预览中移除该多余括号。仅在候选完整合法且结果唯一时接受，不与注释、尾逗号等修复叠加，混合引号、残缺内容或无法唯一确认时拒绝并保留原文。修复输出沿用现有 JSON 格式化，Unicode 转义可能规范化为对应字符，字符串值不变；也支持将空白（空格、制表符、CR/LF 换行）分隔的至少两条完整 JSON 对象/数组合并为一个合法数组，经已有差异预览确认后应用。多记录合并要求原始记录均为合法 JSON，直接保留各记录文本，因此不改变“详情”等字符串的类型、转义内容、数字原始精度或重复键顺序；尾部垃圾、残缺记录、无空白相邻记录、标量记录及需额外语法修复的多记录输入均拒绝合并并保留原文。已有单顶层 JSON 行为保持不变。XML 修复仅处理裸 `&` 与明确的无引号属性值（紧邻 `/>` 的属性末尾 `/` 有歧义时拒绝修复）。不推断缺失的值、闭合结构、标签名称或未知实体。结构化选区必须是完整 JSON 值、上述完整 JSON 记录序列或 XML 文档，无法恢复则显示中文错误及可获得的文档行列位置，保留原文。

JSON/XML/SQL 预览只显示着色后的源码，不执行脚本或 SQL。XML 格式化会规范化引号、空元素写法和缩进；混合内容及 xml:space="preserve" 保留，不支持带 DTD/实体声明的文档格式化。SQL 格式化不执行语句，也不验证数据库方言或表结构。

正则查找采用标准 Python 表达式语法，不支持递归等引擎扩展。每次操作预算为 0.25 秒，超时会提示简化表达式；表达式最多 4096 字符，正则替换模板最多 65536 字符。替换先生成结果再写入，失败时保留原文，全部替换支持一步撤销。

## 卸载

通过 Windows 设置中的“已安装的应用”卸载 Notepad View，或右键安装目录的 `uninstall.ps1` 选择“使用 PowerShell 运行”。卸载前关闭应用。卸载仅删除安装清单中的程序文件，保留用户文档和工作区缓存；主题、默认视图及最近文件偏好保留在当前用户注册表 `HKCU/Software/NotepadView/NotepadView`。

首次安装目录必须为空。再次安装时，安装器优先使用当前用户卸载注册信息中有效的旧安装位置，也可手动选择原目录升级。仅自动覆盖包含有效 `notepadview-install.json`（应用标识为 `NotepadView`、登记程序文件）及有效程序文件的本应用安装；未知非空目录仍拒绝安装。升级替换已登记程序文件、移除旧版已登记文件，并保留额外用户文件、配置和工作区；若新程序文件与未登记的用户文件重名则停止安装。升级先准备完整 staging 目录，再备份旧目录并切换，切换失败恢复旧目录。安装前请关闭应用及占用安装目录的程序；安装器不会强制结束进程。升级后沿用现有注册与快捷方式更新逻辑。

## macOS Apple Silicon 构建（准备阶段）

需在 **macOS 13+、Apple Silicon、原生 arm64 Python 3.11–3.14** 上构建，建议使用 python.org 的 Python 3.12。当前只在 Windows 上完成脚本检查及外部工具模拟测试，**尚未在真实 Mac 构建或运行，未产出真实 DMG**。Windows 无法交叉生成此安装包。

在项目根目录的 Mac 终端执行以下命令（命令中的路径分隔符适用于 macOS）：

```bash
python3.12 -m venv .venv-macos
.venv-macos/bin/python -m pip install --only-binary=:all: -r requirements-macos.txt
.venv-macos/bin/python scripts/build_macos.py
```

PyPI 锁定版 `pyside6-scintilla==5.6.3.7` 提供 `cp311-abi3-macosx_13_0_arm64` 轮子，PySide6 6.11.1 提供 macOS 13+ universal2 轮子，PyInstaller 6.22.3 也提供 universal2 轮子。安装命令只接受二进制轮子，避免意外进入本地源码编译。若解释器运行在 Rosetta/x86_64 下，退出 Rosetta 终端，使用原生 arm64 Python 重新创建虚拟环境；脚本会拒绝错误平台和架构。无需在 Windows 安装这些 macOS 构建依赖。

脚本从 `logo` 中的高分辨率品牌源图生成原生 `.icns`，使用 PyInstaller 的 `--target-arch arm64` 和标识 `com.notepadview.app`，收集 Scintilla、SQL、Pygments、Qt PDF 及 WebEngine。构建中间文件仅放在 `build/macos/run-*`，结束或失败时只清理本次目录。Windows 构建脚本、根目录依赖锁、`dist` 中的 Windows 产物和校验和不变。

成功后在 `dist/macos` 下生成：

- `Notepad View.app`：包含运行时、资源、README、第三方声明、构建依赖锁及 `Contents/Resources/licenses` 中的许可证。
- `NotepadView-1.0.0-macOS-arm64.dmg`：打开后将应用拖到 `Applications` 链接即可安装，运行时不需要另装 Python。
- `SHA256SUMS.txt`：仅在应用和 DMG 存在且签名完整性、磁盘镜像验证通过后写入。失败时不保留成功校验和；已有旧产物不能视为本次成功。

重新构建前先将已有的 `dist/macos/Notepad View.app` 移到其他位置；脚本不会删除旧应用。Mac 上可运行 `cd dist/macos`，再运行 `shasum -a 256 -c SHA256SUMS.txt` 核对镜像。

当前仅进行本地 **ad-hoc 签名**，没有 Developer ID 证书，未经过 Apple 公证；Gatekeeper 仍可能阻止打开。确认来源及摘要后，可按 macOS 系统设置“隐私与安全性”提供的针对该应用的“仍要打开”操作，不需要全局关闭 Gatekeeper。正式分发前需在真实 Mac 验证启动、编辑、PDF/WebEngine 和拖放安装，并补齐 Developer ID 签名、公证与 stapling；这些步骤未由当前脚本实现。
